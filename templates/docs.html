Send previews to Playcheck Cloud

Three steps: create a project to get an upload token, run playcheck in CI, upload the event stream. The dashboard renders exactly what the CLI saw — including every task that could not be simulated.

1 · Get an upload token

Create a project from your dashboard — the token (pck_…) is shown once. Store it as a CI secret named PLAYCHECK_TOKEN. Admins can rotate it any time from project settings.

2 · GitHub Actions (recommended)

The public Action posts the preview as a PR comment; the two optional inputs below also upload it here. 

name: playcheck
on: pull_request

jobs:
  preview:
    runs-on: ubuntu-latest
    permissions:
      pull-requests: write
    steps:
      - uses: actions/checkout@v4
      - uses: Cjayy77/Playcheck@v1
        with:
          playbook: site.yml
          inventory: inventories/production
          upload-url: https://{{ request.get_host }}
          api-token: ${% templatetag openvariable %} secrets.PLAYCHECK_TOKEN {% templatetag closevariable %}

3 · Any other CI (plain curl)

Save the raw JSONL event stream with --save-events and POST it verbatim. Metadata travels as query parameters; all are optional. 

pip install playcheck
playcheck run site.yml -i inventories/production \
  --quiet --save-events events.jsonl

curl -sS --fail -X POST \
  "https://{{ request.get_host }}/api/v1/previews?repo=$CI_REPO&branch=$CI_BRANCH&commit=$CI_COMMIT&actor=$CI_USER" \
  -H "Authorization: Bearer $PLAYCHECK_TOKEN" \
  --data-binary @events.jsonl

API notes

  • Endpoint: POST /api/v1/previews — versioned; old CLI versions keep working.
  • Body: the playcheck JSONL event stream, verbatim. Query params: repo, branch, commit, pr, actor.
  • Returns 201 with the preview URL and summary counts.
  • Rate limit: 30 uploads per project per minute (429 beyond).
  • Secrets never reach us: no_log and diff: false content is censored by Ansible before the CLI ever sees it.
